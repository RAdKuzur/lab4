# Trace Collector: Минимально жизнеспособный продукт (MVP)

Данный программный прототип разработан в рамках курсовой работы по дисциплине «Междисциплинарный проект» (уровень магистратуры, направление 09.04.02 «Информационные системы и технологии»).

**Тема исследования:** Разработка системы распределённой трассировки для анализа взаимодействия микросервисов.

## 1. Быстрый запуск (Quick Start)

Для запуска прототипа необходимо выполнить следующие команды:

```bash
# 1. Подготовка конфигурации окружения
cp .env.example .env

# 2. Сборка и запуск контейнеров
docker compose up --build -d
```

После успешного запуска контейнеров веб-интерфейс системы будет доступен по следующим адресам:

- **Главная страница UI:** http://localhost:8080/
- **Детализация трассировки:** http://localhost:8081/

Для появления трассировок необходимо перейти на страницу http://localhost:8081/, после чего можно просмотреть результаты взаимодействия микросервисов.

## 2. Проверка работоспособности

Для выполнения автоматизированной проверки работоспособности прототипа предусмотрен скрипт:

```bash
python scripts/verify.py
```

Скрипт выполняет контрольные проверки основных компонентов системы.

## 3. Запуск автоматизированных тестов

Для отдельного тестирования компонентов системы предусмотрены два набора тестов.

**Тестирование модуля трассировки:**

```bash
docker compose up --build tests-collector
```

**Тестирование пользовательского интерфейса (UI):**

```bash
docker compose up --build tests-ui
```

Каждый набор тестов выполняется в отдельном Docker-контейнере, что обеспечивает изоляцию тестового окружения.
